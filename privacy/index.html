01기본 원칙

Swiss Fare Check(이하 “사이트”)는 스위스 여행 루트와 교통패스 비용을 비교할 수 있도록 돕는 독립적인 웹 도구입니다. 사이트는 서비스 제공에 필요한 범위에서만 정보를 처리하며, 이용자의 계산기 입력값을 회원 프로필이나 마케팅 명단으로 만들지 않습니다.

02처리할 수 있는 정보

  • 계산기 입력값: 여행 인원, 날짜, 노선, 패스 선택과 직접 입력한 요금
  • 브라우저 저장 정보: 사용 중인 기기에서 계산 상태를 복원하기 위한 로컬 저장 데이터
  • 문의 정보: 이메일로 문의할 때 이용자가 직접 제공한 이메일 주소, 이름 또는 닉네임, 문의 내용
  • 접속 정보: 호스팅 제공자가 보안과 장애 대응을 위해 자동으로 처리할 수 있는 IP 주소, 접속 시각, 브라우저·기기 정보, 요청 기록
  • 광고 관련 정보: 광고가 게재되는 경우 광고 제공자가 쿠키 또는 유사 기술을 통해 처리하는 광고 식별자와 이용 기록
계산기 입력값은 기기 안에서 처리됩니다.현재 사이트의 계산 기능은 브라우저에서 실행되며, 입력한 여행 계획과 요금을 사이트 운영자에게 전송하지 않습니다.

  • 이용자는 Google 광고 설정에서 맞춤형 광고 사용 여부를 관리할 수 있습니다.
  • 광고 기술과 데이터 이용 방식은 Google의 광고 정책 안내에서 확인할 수 있습니다.
  • 브라우저 설정에서 쿠키를 삭제하거나 차단할 수 있지만, 일부 광고·환경설정 기능이 제한될 수 있습니다.
